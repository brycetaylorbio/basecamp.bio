Keyboard entry accepts A/C/G/T for DNA, A/C/G/U for RNA, and the 20 standard amino acid letters plus * for protein. Shortcuts use keys outside these alphabets and work while you type in Entry. Entry holds 24 nucleotide letters or 8 protein letters. Use Builder for longer sequences; Append Entry joins the current chunk to it. Pasting uses the same letters as typing; ambiguity codes are not accepted. Builder changes alphabet with Entry, uses frame +1 for protein, and restores its original source when available. Game: Space starts a round. The timer stops when the correct tenth letter is typed; mistakes keep it running. Each command keeps one best time on this device. A new winner can enter a six-letter DNA name and press Enter to save. T and U cannot be mixed. Plain sequences and single-record FASTA are accepted. “To RNA” swaps T for U; it does not make the complementary strand.
“To protein” uses the standard genetic code and the frame selected in Frames (default +1), reads through stop codons as *, and omits trailing incomplete codons. From protein, To DNA/RNA restores the exact input sequence if you converted it here and have not edited the protein. Otherwise it uses one fixed codon per amino acid, with TAA for stop (*). This produces a possible coding sequence; synonymous codons mean the original sequence cannot be inferred from protein alone.
Color: A green, C blue, G amber, T/U red. Protein colors group hydrophobic, polar, positively charged, negatively charged, and special residues.
