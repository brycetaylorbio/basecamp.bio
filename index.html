Base Camp (get it? It's like DNA...)

A collection of playful ways to explore biology.

The resources on this site are an expression of my vision of biology as a living science that you should interact with in order to understand.
All ideas and curricula are my own. Game and apps are coded primarily by AI.
My goal is to gain feedback on these so that I can apply for grant funding so I can hire a human developer to build versions of each app that can be shared broadly.
